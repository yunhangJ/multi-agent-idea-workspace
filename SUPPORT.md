# Support

This is an early personal project, not a supported commercial service.

- Use GitHub Issues for reproducible bugs and narrowly scoped feature proposals after the repository is published.
- Do not post API keys, endpoint URLs, real workspace exports, imported private files, local logs, or screenshots of AI settings.
- Security-sensitive reports belong in GitHub Private Vulnerability Reporting once it is enabled; see `SECURITY.md`.
- Questions about a third-party proxy, account, billing, model availability, or API quota should be directed to that service rather than this project.
