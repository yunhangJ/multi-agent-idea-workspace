# Code of Conduct

## Our standard

Project discussions should be respectful, specific, and focused on improving the software. Harassment, discrimination, personal attacks, doxxing, and publication of another person's private data or credentials are not acceptable.

## Expected behavior

- Critique ideas and code rather than people.
- Provide evidence and reproducible examples where possible.
- Respect privacy boundaries, especially around workspaces, prompts, imported documents, API configuration, and Agent histories.
- Accept that maintainers may reject changes that weaken data isolation, security, accessibility, or project scope.

## Enforcement

Maintainers may edit or remove comments, commits, issues, and contributions that violate this policy, and may temporarily or permanently restrict participation. Enforcement decisions should be proportionate and documented privately when personal data is involved.

Until a dedicated conduct contact is published, do not send sensitive personal information through public issues. Use GitHub's abuse-reporting and moderation tools for urgent platform-level concerns.
